# Tech Store

Простой интернет-магазин с товарами, категориями и сортировкой по цене.  

## Функционал
- Просмотр товаров с карточками (изображение, название, цена, рейтинг)  
- Сортировка товаров по цене (по возрастанию и убыванию)  
- Категории товаров  
- Адаптивная верстка под мобильные устройства  

## Технологии
- React + TypeScript  
- Sass (SCSS) для стилей  
- Node.js + Express для простого API  
- JSON-файл как мок-данные товаров  

## Установка и запуск
1. Склонируйте репозиторий:  
```bash
git clone <url>

2. Установите зависимости:
  npm install

3. Запустите фронтенд:
  npm run dev

4. Запустить тесты
  npm run test

5. Запустить билд
  npm run build
